Sightline

A public window on Tacit — both chains, the bridge, and the privacy boundary.

This page never asks for a seed phrase or private key, never connects a wallet, and never moves funds. Every figure is fetched in your browser from official Tacit APIs, public RPCs, or Bitcoin explorers. If a source is delayed, blocked, or disagrees with another, that is shown rather than hidden.

This only shows what is already public. A tacit1 ID opens the official tacitscan page. An EVM address is resolved on Ethereum and Base (balances, canonical Tacit tokens, XNS name). Nothing confidential can appear here, by design.

    Provenance

    Contracts, APIs, and how this page fetches them

    Official documentation and addresses are taken from src-company/tacit docs/DEPLOYMENTS.md, tacit.finance/build, and XNS v2. The public API is api.tacit.finance (no key).

    Some official API routes (/assets, /amm/pools, /market) send Access-Control-Allow-Origin: https://tacit.finance, so a third-party page cannot read them directly in the browser. Sightline tries a direct request first, then — only if the browser blocks it — refetches the same official URL through allorigins, and labels that path. You can always open the official JSON yourself. Everything else used here already allows any origin, or is a public Ethereum/Bitcoin RPC.
